# Morph photo source audit — 2026-09-30

## Scope and method

This read-only audit looked for Western Hognose (*Heterodon nasicus*) captive morph photos with a specific visible-morph claim and rights evidence that permits reuse in HogMorph Studio. It used web search and opened source/policy pages, then queried the Hognose Wiki MediaWiki API for the `Category:Morphs` pages and file namespace. On 2026-09-30, the API inventory returned 77 pages in `Category:Morphs` and 124 file pages overall. A quick gallery-wikitext scan found approximately 48 morph-gallery slots. That gallery scan's one-off extraction script was not retained, so the slot count cannot be exactly reproduced from an archived script; it remains **approximate and unverified**. It includes possible duplicate images, has not had image-by-image species/label review, and is not a count of eligible assets. The file inventory contains non-photo interface art and images of other species. No images were downloaded, copied, or added to the project, and nobody was contacted.

The exact API query parameters used for the inventory were:

- Morph category members: [`https://hognose.fandom.com/api.php?action=query&list=categorymembers&cmtitle=Category%3AMorphs&cmlimit=500&format=json`](https://hognose.fandom.com/api.php?action=query&list=categorymembers&cmtitle=Category%3AMorphs&cmlimit=500&format=json) (`action=query`, `list=categorymembers`, `cmtitle=Category:Morphs`, `cmlimit=500`, `format=json`). On the audit date it returned 77 entries and no continuation token.
- File namespace inventory: [`https://hognose.fandom.com/api.php?action=query&list=allpages&apnamespace=6&aplimit=500&format=json`](https://hognose.fandom.com/api.php?action=query&list=allpages&apnamespace=6&aplimit=500&format=json) (`action=query`, `list=allpages`, `apnamespace=6`, `aplimit=500`, `format=json`). On the audit date it returned 124 entries and no continuation token.

These endpoints are live inventories and may change after the audit date. They reproduce the page/file counts, not the approximate gallery-slot count or reuse eligibility. The current gallery contents and each file's rights/label evidence need fresh review before use.

## What an outreach grant must cover

Request permission from the photographer/copyright holder (or a documented agent authorized to grant it), separately for each image unless the grant clearly covers a named collection. The written grant or explicit per-file license should identify:

1. The image(s) by stable source URL/file ID and original author; confirmation the grantor owns or controls the relevant rights.
2. Permission to copy, store, resize/crop/orient, convert formats, remove embedded personal metadata, and otherwise preprocess the image.
3. Permission to use the images for machine-learning training, validation, and independent testing, and to retain derived annotations/features and publish aggregate evaluation results.
4. Permission to display the images in the HogMorph Studio demo, competition submission, screenshots/video/poster, and project website/repository; state separately whether downloadable image redistribution is allowed. Specify any duration, territory, attribution, commercial-use, and share-alike conditions.
5. Confirmation of captive Western Hognose species and a stable individual ID (or explicit photo-session grouping so images of one animal cannot cross evaluation splits); breeder/owner provenance; claimed expressed morph and its minimum base-trait decomposition; and supporting pedigree/genetic or breeder evidence. Mark possible hets, unverified labels, and polygenic claims separately from visually expressed traits.
6. Permission for the accompanying animal/owner information to be retained with the image, plus any privacy restrictions. Keep the grant, source URL, attribution, license, modifications, and file hash in the per-image manifest.

Until those records exist and an independent reviewer verifies each sample, count these leads as **zero eligible morph-training images**. Split evaluation data by individual snake (and preferably breeder/source) to prevent photos of the same animal leaking across train and test sets.
